# OpenDoors

Find and review places by how accessible they are. iOS and Android, built with Expo SDK 57.
See `CLAUDE.md` for the stack, structure and accessibility rules.

## Prerequisites

- Node.js 24 LTS and npm
- Xcode with an iOS simulator (macOS only), and/or Android Studio with an emulator
- For iOS builds: CocoaPods (`brew install cocoapods`)

This project uses development builds (`expo-dev-client`). Expo Go is not supported.

## Setup

```sh
npm install
cp .env.example .env
```

Fill in `.env` from the Supabase dashboard (Connect panel):

```
EXPO_PUBLIC_SUPABASE_URL=https://<project-ref>.supabase.co
EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
```

Only the publishable key belongs here. Never put a secret or service-role key in this repo.
The app still starts without `.env`; Supabase features report that they are not configured.

## Development builds

`ios/` and `android/` are generated by these commands and are not committed.

```sh
npx expo run:ios       # builds, installs on the iOS simulator, starts Metro
npx expo run:android   # builds, installs on the Android emulator, starts Metro
```

After the first build, `npx expo start` is enough until native dependencies or `app.json` change.
In development builds, the Explore tab has an "Open design tokens" button for the token reference screen.

## Checks

```sh
npm run check        # lint (ESLint + react-native-a11y) and typecheck
npx expo-doctor      # after any dependency change
```
